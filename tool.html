工具介绍

UltraTexture Studio 支持文生图、图生图、MC 像素贴图、批量生成、拼图与本地 MCP Bridge。程序不会提供或托管图像模型服务；启动后请在“设置”中填写自己的 API Key、Base URL、模型、代理与 User-Agent。

在“设置 → OTA 更新清单 URL”中填写 https://sjhc1995.github.io/ultratech/releases/ultratexture/manifest.json 后，可从应用内检查、下载、校验并安装后续更新。Windows 可能会对未签名的本地开发工具显示安全提示；请仅从本页下载，并在运行前核对上方 SHA-256。
